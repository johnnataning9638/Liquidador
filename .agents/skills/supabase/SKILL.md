# supabase
Inspeccionar esquema, consultas, políticas RLS, permisos, integridad y migraciones cuando el cambio impacte base de datos. Nunca ejecutar operaciones destructivas ni modificar datos productivos sin autorización expresa. No tocar Supabase si no aplica.
## Validación
Ejecutar las comprobaciones correspondientes, conservar evidencia, corregir solo dentro del alcance autorizado y declarar cualquier verificación pendiente.
