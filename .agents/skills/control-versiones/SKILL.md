# control-versiones
Identificar la fuente de versión actual. Incrementar versión de código en cada cambio aprobado, sincronizar manifestaciones pertinentes y CHANGELOG. Registrar commit, versión anterior/nueva y procedimiento de reversión; no actualizar librerías sin necesidad.
## Validación
Ejecutar las comprobaciones correspondientes, conservar evidencia, corregir solo dentro del alcance autorizado y declarar cualquier verificación pendiente.
