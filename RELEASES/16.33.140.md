# v16.33.140

## Corrección — LIMPIAR global desde TÍTULOS / TJ

Se corrige el comportamiento observable del botón **LIMPIAR** ubicado en la pestaña **TÍTULOS / RESULTADOS** del módulo TDJ.

### Comportamiento esperado

Al pulsar **LIMPIAR** desde TÍTULOS/TJ y confirmar:

- se eliminan los TÍTULOS / TDJ registrados;
- se limpian los datos de identificación y obligaciones de **Datos y vencimientos**;
- se eliminan los **Pagos**;
- se limpia el resultado de la liquidación;
- se limpia el contenido residual del importador de títulos;
- el módulo queda completamente listo para iniciar una nueva liquidación.

### Corrección técnica

El motor TDJ ya dispone de `limpiarTodo()` y el controlador de `.btn-limpiar-tdj` direcciona la pestaña TÍTULOS/TJ hacia esa función. La incidencia observada provenía de que `titulos.html` continuaba cargando una referencia cacheable antigua de `tdj.js` (`v16.33.123`).

Se actualiza el versionado de carga del módulo a **v16.33.140** para forzar la carga del código vigente y evitar que el navegador ejecute el controlador anterior de limpieza exclusiva de títulos.

### Alcance protegido

No se modifican:

- fórmulas de liquidación;
- proporcionalidad de pagos/Títulos;
- cálculo de intereses;
- cálculo o actualización de sanciones;
- reglas de endoso;
- cursor/secuencia de aplicación de TDJ;
- parámetros tributarios;
- estructura de Supabase.
