# v16.33.189 — Homologación visual PDF TJ/TDJ con resumen DIAN

## Cambio
- Se corrige exclusivamente la presentación del bloque final del PDF TJ/TDJ.
- El resumen final adopta la misma arquitectura visual del resumen del Liquidador DIAN:
  - encabezado DIAN;
  - tarjetas de indicadores en 3 columnas;
  - tablas compactas con los mismos bordes, tamaños, fondos y tipografía;
  - bloque amarillo de excedentes;
  - bloque de títulos y endoso con la misma composición;
  - márgenes A4 de 22 mm.
- Cada bloque de resumen final ocupa una sola página, evitando que el contenido quede comprimido, separado o distribuido accidentalmente entre hojas.
- Se conserva el orden: liquidaciones individuales → resumen final → consolidación de excedentes → resumen de títulos y endoso.

## No modificado
- Motores de liquidación.
- Intereses.
- Sanciones y actualizaciones.
- Distribución proporcional.
- Cronología de pagos y títulos.
- Endoso/remanentes.
- Importadores.
- Excel.
- Supabase.
- Interfaz operativa del módulo TJ.

## Base de referencia
La estructura visual fue homologada directamente con la arquitectura de `estilosPdf()` y las funciones de resumen final del Liquidador DIAN, manteniendo el contenido propio del módulo TJ/TDJ.
