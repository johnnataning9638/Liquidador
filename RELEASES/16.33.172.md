# RELEASE 16.33.172 — TDJ / SECUENCIA DE TÍTULOS CON MISMA FECHA

## Objetivo
Corregir en el módulo TDJ la aplicación secuencial de títulos cuando existen dos o más TDJ con la misma fecha y existen pagos normales posteriores.

## Caso de referencia
Se comparó una liquidación DIAN correcta contra una liquidación TDJ incorrecta con:
- 4 TDJ con fecha 24/07/2026.
- Valores: $500.000, $500.000, $20.000.000 y $10.000.000.
- Pagos normales posteriores, incluido el pago del 01/10/2026.

El comportamiento DIAN reserva la capacidad necesaria para el pago normal posterior. En consecuencia, el TDJ de $20.000.000 queda aplicado por $15.548.000 y el TDJ siguiente de $10.000.000 queda íntegramente para endoso.

## Corrección
Se creó `js/tdj-tasa-bridge-16.33.172.js` como capa aislada.

La capa:
1. Conserva el puente de tasa por TÍTULO × OBLIGACIÓN de 16.33.171.
2. Conserva las restricciones de vigencia de beneficios.
3. Detecta el TDJ actual y los TDJ anteriores de la misma fecha.
4. Si existen pagos normales posteriores, simula el comportamiento completo hasta la fecha del último pago normal.
5. Si el valor completo del TDJ actual genera excedentes en pagos normales posteriores, determina mediante búsqueda binaria el máximo valor del TDJ que permite aplicar íntegramente esos pagos normales.
6. El resultado se entrega al motor histórico para la liquidación definitiva.
7. Si el valor permitido del TDJ es cero, el módulo conserva el título completo como remanente para endoso y permite que continúe hacia la siguiente obligación cuando corresponda.

## Preservación
- `js/tdj-core-16.33.143.js` NO fue modificado.
- `js/motor-liquidacion.js` NO fue modificado.
- `js/motor-liquidacion-base.js` NO fue modificado.
- `js/prioridad-tdj.js` NO fue modificado.
- La corrección se limita a la capa TDJ.

## Resultado esperado del caso de prueba
- TDJ 1: aplicado $500.000.
- TDJ 2: aplicado $500.000.
- TDJ 3: aplicado $15.548.000; endoso $4.452.000.
- TDJ 4: aplicado $0; endoso $10.000.000.
- Endoso total: $14.452.000.
