# VERSIÓN 16.33.130

## CORRECCIÓN — PRIORIDAD DE PAGOS REALES SOBRE TDJ

### Regla aplicada
- Los pagos reales del contribuyente tienen prioridad sobre los TDJ, incluso cuando el pago real ocurre después de un título.
- Los TDJ anteriores se mantienen aplicados en la secuencia mientras todavía exista saldo que deba cubrirse.
- Cuando un TDJ es el último título necesario para cubrir la obligación frente a un pago real posterior, se utiliza únicamente el valor necesario y el remanente queda para endoso.
- Los TDJ posteriores al título que cerró la obligación no regresan a consumir esa obligación; quedan disponibles para endoso o para la siguiente obligación cuando corresponda.
- Se conserva el arrastre de sobrantes entre obligaciones y el cursor persistente de la cadena TDJ.
- No se modifican las fórmulas del motor base, Régimen Simple, liquidaciones oficiales ni la estructura de Supabase.
