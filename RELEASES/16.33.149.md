# v16.33.149 — CORRECCIÓN SECUENCIA TDJ

## Novedad corregida

Se corrige la aplicación de múltiples TDJ con la misma fecha cuando existen varias obligaciones y pagos normales posteriores.

## Regla funcional

1. Los títulos se procesan cronológicamente.
2. Mientras la obligación actual conserve saldo, los títulos de la misma fecha continúan atendiendo esa obligación.
3. Una vez cubierta la obligación, el remanente del título continúa con la siguiente obligación.
4. Si existe un pago normal posterior a un TDJ, el TDJ se ajusta únicamente hasta el punto que permita que el pago posterior se aplique íntegramente.
5. No se modifica la proporcionalidad económica del motor ni la prioridad de los pagos normales.

## Corrección técnica adicional

Se detectó que `tdj-core-16.33.143.js` todavía cargaba la capa de secuencia con referencias de versión antiguas (`v16.33.136`). Se actualizan las referencias críticas a `v16.33.149` para impedir que el navegador ejecute una copia cacheada de la capa anterior.

## Pruebas

- Regresión de pago posterior: aprobada.
- Regresión de segundo TDJ de misma fecha después de cerrar obligación: aprobada.
- Regresión de TDJ de misma fecha cuando la obligación aún tiene saldo: aprobada.
- Auditoría de estabilidad del liquidador: aprobada.
- Regresión de importadores decimales: aprobada.
- Regresión de limpieza global/resumen TDJ: aprobada.

## Evidencia de usuario analizada

El soporte de 11 páginas suministrado muestra títulos del 24/07/2026 y, en el resumen final, el pago 3 por $8.193.000 tratado como excedente. Esa evidencia se utilizó como caso de regresión para esta versión.
