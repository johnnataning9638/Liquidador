# v16.33.162 — DISEÑO VISUAL DE BENEFICIOS POR OBLIGACIÓN EN TDJ

- Se migra a la interfaz web del módulo TDJ la estructura visual de títulos con columnas dinámicas `OBLIGACIÓN 1`, `OBLIGACIÓN 2`, `OBLIGACIÓN 3`, etc.
- Cada título muestra una lista desplegable visual de beneficio por obligación.
- La cantidad de columnas se ajusta automáticamente al número de obligaciones registradas.
- Se conserva en el DOM el campo de observación existente, ocultándolo únicamente a nivel visual para no afectar estado, importación ni cálculo.
- Se conserva la acción original de eliminar título.
- Los selectores de beneficio son exclusivamente visuales y no alimentan el motor de liquidación.
- No se modifican `tdj-core-16.33.143.js`, motores, fórmulas, pagos, resultados ni reglas de cálculo.
