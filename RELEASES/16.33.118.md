# 16.33.118 — IMPORTACIÓN OPCIONAL Y CAPTURA MANUAL

- Importar es opcional en DIAN y TDJ.
- La captura manual es una fuente válida.
- Antes de calcular TDJ se sincronizan cuotas, pagos y títulos visibles con el modelo interno.
- Las validaciones comprueban datos requeridos, no el origen de los datos.
- Se preservan DIAN tradicional, Régimen Simple, sanciones, intereses, cuotas, pagos, TDJ, distribución, endoso y fecha de corte.
