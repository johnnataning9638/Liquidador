# VERSIÓN 16.33.129

## CORRECCIÓN — SECUENCIA DE APLICACIÓN DE TDJ ENTRE OBLIGACIONES

### Regla corregida
- Los pagos normales y los TDJ se siguen procesando cronológicamente dentro de cada obligación.
- Un TDJ aporta únicamente el valor necesario para cubrir el saldo real de la obligación después de considerar los pagos que correspondan.
- El excedente de un TDJ se arrastra a la siguiente obligación junto con los títulos que aún no se hayan utilizado.
- Una obligación que ya quedó cubierta queda cerrada para la cadena de TDJ.
- Los títulos posteriores no pueden regresar a una obligación anterior ya cubierta.
- Si varios títulos cubren una obligación, solo el último título necesario puede quedar parcialmente aplicado; su saldo continúa a la siguiente obligación.
- Si todas las obligaciones quedan cubiertas antes de consumir los títulos, los títulos y saldos restantes quedan disponibles para endoso.
- Se conserva la lógica especial existente para TDJ de cuantía <= $1.000.
- No se modifican las fórmulas del motor base, la lógica de Régimen Simple, liquidaciones oficiales, proporcionalidad ni Supabase.
