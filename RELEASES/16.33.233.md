# 16.33.233 — Importación sin IA y cierre de prioridad TDJ

Base: main 16.33.231, commit 18cd6ba645b7d40bd0f3f8f8587c145c1fd7d946. La propuesta 232 de recibos compartidos permanece fuera de esta versión.

Se eliminan la interfaz y los consumidores de importación IA en DIAN y TDJ, incluido ai-bridge.js, las consultas de conexión y el envío de ejemplos al limpiar. Se conserva la importación normal y se simplifican sus acciones móviles.

Se corrige además el fallo de prioridad TDJ autorizado durante la auditoría. La búsqueda del máximo título compatible con un pago posterior podía consumir $1.000 aun cuando el escenario sin el título ya cerraba la deuda. Ahora se comprueba primero ese cierre. Si el título queda excluido, no se reutiliza el detalle de otro movimiento. El nominal no se altera en la captura y queda disponible para otra obligación o endoso.

El caso crítico continúa exigiendo títulos por $31.000.000, aplicado $16.548.000, endoso $14.452.000 y cuarto título íntegro por $10.000.000. Se verifican pantalla, PDF, Excel y recálculo. No se modifican las fórmulas de los motores compartidos DIAN/TDJ, las tablas de tasas ni los importadores normales.

La fuente de versión es version.json. Las dependencias sin cambios conservan sus identificadores de caché históricos. Se actualizan las entradas, CSS, core y módulo de prioridad afectados, el guard de navegación y las versiones visibles.

No requiere una migración Supabase. Las tablas de IA se conservan para evitar eliminación de datos históricos; los clientes del liquidador ya no las usan. No se eliminan servicios remotos que podrían servir a otros consumidores.

Validación y limitaciones: docs/auditoria-16.33.233.md. Publicar únicamente después de comprobar CI y validar el despliegue específico de Render.

Reversión: desplegar el commit base 18cd6ba645b7d40bd0f3f8f8587c145c1fd7d946. Esto recupera la interfaz IA y el defecto previo de prioridad; no hay una migración de datos que revertir.
