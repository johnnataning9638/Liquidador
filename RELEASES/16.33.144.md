# RELEASE 16.33.144 — LIMPIAR GLOBAL TDJ

## Auditoría

- La fuente actual de `titulos.html` no contiene el mensaje antiguo de limpieza exclusiva de títulos.
- El comportamiento observado es consistente con ejecución de un `js/tdj.js` cacheado por ruta.
- Para aislar el problema se conserva el motor original íntegro y se crea una ruta física nueva para su código.

## Corrección

- `js/tdj.js` pasa a ser una barrera liviana que captura el botón TÍTULOS/TJ `LIMPIAR` antes de cualquier listener antiguo/cacheado.
- El motor original queda íntegro en `js/tdj-core-16.33.143.js`.
- La limpieza desde TÍTULOS/TJ inicia una nueva liquidación y elimina Datos/vencimientos, Pagos, Títulos/TDJ y Resultados.
- No se modifica proporcionalidad, intereses, sanciones, cursor, endoso ni reglas de cálculo.

## Validación

- Se conserva exactamente el blob original del motor.
- Se valida sintaxis del nuevo `js/tdj.js`.
- Se valida que el mensaje antiguo no exista en el loader ni en la fuente actual de TÍTULOS.
