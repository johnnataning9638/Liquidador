# RELEASE 16.33.141 — TDJ / RESUMEN FINAL Y LIMPIEZA GLOBAL

## Correcciones

### 1. LIMPIAR desde TÍTULOS / TDJ
- Se blinda el botón LIMPIAR de la pestaña TÍTULOS/TDJ para iniciar una nueva liquidación completa.
- La acción elimina del estado de trabajo: datos, vencimientos, pagos, títulos y resultados.
- Se bloquean listeners antiguos/cacheados para impedir que vuelva a aparecer el mensaje de limpieza exclusiva de títulos.
- Se fuerza una URL de reinicio con parámetro temporal.

### 2. Resumen final PDF
- Los **EXCEDENTES DE PAGOS** y los **TÍTULOS PARA ENDOSO** quedan en **una misma hoja de resumen final**.
- Ya no se genera una hoja independiente para cada concepto.
- El resumen final se genera aunque un TDJ registrado no haya sido aplicado a ninguna obligación.
- Se muestra el número del TDJ, fecha, valor original, sobrante y destino ENDOSO.
- Si el título fue parcialmente aplicado, se muestra únicamente el saldo disponible para endoso.
- Si fue completamente aplicado, no aparece como título para endoso.
