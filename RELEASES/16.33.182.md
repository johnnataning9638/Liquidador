# RELEASE 16.33.182 — TDJ / CIERRE DE SECUENCIA CON FECHAS IGUALES

## CORRECCIÓN

Se corrige exclusivamente la secuencia de aplicación de títulos TDJ cuando varios títulos tienen la misma fecha.

### Regla implementada

- La fecha continúa siendo utilizada para ordenar cronológicamente.
- La igualdad de fecha NO puede reabrir una obligación que ya quedó cerrada.
- Cuando existe un TDJ anterior de la misma fecha y, al retirar el TDJ actual, los pagos normales posteriores cierran efectivamente la obligación, el TDJ actual queda con **$0 aplicado**.
- El título conserva íntegramente su valor nominal para la siguiente obligación / endoso.
- La prueba de cierre usa el resultado del motor y el saldo/aplicación del pago normal posterior; no se infiere el cierre mediante sumas nominales.
- Se incorpora bypass de recursión para que las pruebas internas de `prioridad-tdj-v132` utilicen el motor original y no vuelvan a ejecutar la guardia de secuencia.

## CASO DE REFERENCIA
