# VERSIÓN 16.33.180 — IMPORTACIÓN EXCEL DESDE RECUPERACIÓN COMPLETA

## CORRECCIÓN
Se corrige exclusivamente la fuente utilizada durante la reimportación de Excel del Liquidador normal.

El bloque de resultados **PAGOS Y APLICACIÓN** contiene valores ya aplicados y, para un TDJ, puede mostrar un valor reducido respecto del valor nominal original. Ese bloque no debe utilizarse como fuente de recuperación.

La reimportación de un Excel que contiene **RECUPERACIÓN COMPLETA — DATOS DE TRABAJO (NO MODIFICAR)** ahora utiliza como fuente de verdad:

1. **PAGOS** dentro de RECUPERACIÓN COMPLETA para recuperar todos los pagos registrados.
2. **TÍTULOS TDJ** dentro de RECUPERACIÓN COMPLETA para validar y recuperar el valor nominal, fecha, tipo y observación de cada TDJ.
3. Si un TDJ está en TÍTULOS TDJ pero no aparece en PAGOS, se incorpora como pago TDJ para no perder el título registrado.

## REGLA CLAVE
No se toma el valor de un TDJ desde **PAGOS Y APLICACIÓN**.

Ejemplo validado conceptualmente:
- TDJ nominal: $20.000.000
- Valor aplicado en resultados: $15.548.000
- Valor recuperado para nueva liquidación: **$20.000.000**

## ALCANCE
- No modifica fórmulas del motor de liquidación.
- No modifica la lógica cronológica TDJ/PAGOS.
- No modifica la interfaz.
- No modifica la exportación Excel.
- Corrige únicamente la recuperación posterior a una importación de Excel que contenga el bloque RECUPERACIÓN COMPLETA.
- Los archivos Excel que no contienen RECUPERACIÓN COMPLETA conservan el flujo de importación existente.

## VALIDACIÓN DEL ARCHIVO DE PRUEBA
El Excel suministrado contiene en RECUPERACIÓN COMPLETA:
- 7 pagos completos.
- 4 TDJ registrados.
- TDJ `469030003386680`: $20.000.000.
- TDJ `469030003387674`: $10.000.000.

La corrección está diseñada para recuperar esos valores nominales, no los valores reducidos de la sección PAGOS Y APLICACIÓN.
