# TDJ v16.33.166

## Corrección de importación de títulos / TDJ

Se recupera y refuerza exclusivamente la capa de importación de títulos, sin revertir ni modificar el nuevo diseño visual de OBLIGACIÓN 1..N.

### Reconocimiento conservado y reforzado

- TDJ / RECIBO / DOCUMENTO FUENTE / TÍTULO.
- FECHA / FECHA TDJ / FECHA PRESENTACIÓN.
- VALOR / VALOR TDJ / VALOR PAGADO.
- Tablas pegadas desde Excel con tabulaciones.
- Tablas pegadas desde navegador/Markdown con `|`.
- Separación tradicional por espacios.
- Valores monetarios COP con `$`, puntos o comas.
- Valores provenientes de notación científica de Excel.
- Deducción de registros válidos cuando no existe encabezado estándar.
- Deducción contra duplicados por TDJ + fecha.

### Protección

- No modifica obligaciones.
- No modifica el selector visual de beneficios/tipos.
- No modifica pagos.
- No modifica cálculos, imputación, intereses, sanciones ni resultados.
- El motor TDJ permanece íntegro.
