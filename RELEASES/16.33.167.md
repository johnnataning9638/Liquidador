# TDJ v16.33.167

## Migración de tipo de tasa: obligación → título × obligación

Se migra la aplicación de TIPO DE TASA/TASA desde el nivel global de la obligación hacia cada combinación **TÍTULO / TDJ × OBLIGACIÓN**.

### Nuevo comportamiento

- El selector visible de cada TDJ inicia en `TASA DIAN`.
- Cada TDJ tiene una selección independiente para cada obligación.
- La tasa mostrada corresponde al tipo seleccionado y a la fecha del TDJ.
- La selección de `TDJ 1 → OBLIGACIÓN 1` no modifica `TDJ 2 → OBLIGACIÓN 1`.
- La selección de `TDJ 1 → OBLIGACIÓN 1` tampoco se arrastra automáticamente a `TDJ 1 → OBLIGACIÓN 2`.
- Cuando un TDJ queda con remanente al pasar de una obligación a la siguiente, el remanente se procesa con la selección de tasa correspondiente a **ese mismo TDJ en la nueva obligación**.
- Si un título cubre completamente una obligación, los títulos posteriores no se fuerzan a esa obligación; continúan hacia la siguiente obligación con la configuración de tasa que tengan allí.
- La imputación cronológica, los huecos entre pagos, la proporcionalidad, los saldos arrastrados, la regla de TDJ <= $1.000, el endoso y el cierre de remanentes permanecen bajo el motor existente.

### Compatibilidad

- El campo antiguo TIPO DE TASA/TASA de Datos y vencimientos deja de ser una fuente de cálculo y queda oculto.
- Se conserva internamente como `TASA DIAN` únicamente para compatibilidad con validaciones históricas del módulo.
- El cálculo efectivo de cada TDJ se determina mediante el selector individual TDJ × obligación.
- No se modifica `js/tdj-core-16.33.143.js`.
- La integración se realiza mediante la capa aislada `js/tdj-visual-beneficios.js`.
