# RELEASE 16.33.178 — RECONCILIACIÓN TDJ + CONTROL CANÓNICO EXCEL DIAN

## Corrección funcional
- Se corrigió la causa de TDJ4: la capa de prioridad reducía el TDJ para hacer aplicables pagos posteriores, pero no verificaba el escenario inverso en el que el TDJ era completamente innecesario.
- Cuando existen varios TDJ en la misma fecha, el último título se prueba sin consumirlo. Si los pagos normales posteriores dejan la obligación completamente cubierta, ese TDJ queda en $0 aplicado y conserva el 100 % como remanente/endoso.
- No se modifican las fórmulas de impuesto, intereses, sanción ni proporcionalidad del motor.

## Resultado objetivo del caso crítico
- TDJ1 $500.000 → aplicado $500.000 / endoso $0.
- TDJ2 $500.000 → aplicado $500.000 / endoso $0.
- TDJ3 $20.000.000 → aplicado $15.548.000 / endoso $4.452.000.
- TDJ4 $10.000.000 → aplicado $0 / endoso $10.000.000.
- Total títulos $31.000.000 / total aplicado $16.548.000 / total endoso $14.452.000.
